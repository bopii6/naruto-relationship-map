# legacy — 早期调布局的一次性诊断

这些是 2026/10/18–19 调三视图布局、头像裁切、标签字号时写过的一次性脚本，
**已经不再维护**，留在这里只是留个档。里面的逻辑和当下的 `index.html` 结构可能已经对不上。

| 文件 | 当时用来干什么 |
| --- | --- |
| `preset.cjs` | 一次性渲染 分区 / 分层 / 聚焦 / 情感镜头 四张预设图 |
| `labeldiag.cjs` | 量节点名字标签在缩放后会不会溢出格子 |
| `probe.cjs` | 用 setTimeout 顶替 rAF，绕开无头节流拍补间中间帧 |
| `diag.cjs` | 复用 `../verify.cjs` 的 DOM 桩件，打印每屏的最小间距 |

要重新调布局，直接改 `../verify.cjs` 里的重叠检查，比复活这些脚本划算。
