# assets — 头像源数据

`index.html` 里 37 张头像**已经 base64 内嵌**了，所以这个目录只是源数据，
删掉不影响页面打开。

## 结构

```
assets/
├── avatars/
│   ├── <id>.jpg        ← 最终用的头像，160×160 JPEG，质量 88
│   ├── <id>_src        ← 裁切前的原始立绘（保留原扩展名，无扩展名）
│   └── alternates/     ← 试过但没采用的备选图（鸣人 / 小樱 各一张）
├── avatars.json        ← 上面的 jpg 转成 base64 的集合，也就是内嵌进 HTML 的那份
└── names.txt           ← 当时按 AniList 查角色用的英文名单（含未采用的角色）
```

## 怎么来的

1. 用 AniList 的角色接口按英文名查 `image.large`（官方角色立绘）。
2. 下载后按人脸位置裁成正方形，聚焦头部，缩放到 160×160。
3. 存成 JPEG 质量 88（比 PNG 小一个数量级，1.5 KB vs 30 KB 量级）。
4. 转 base64 写进 `AVATARS` 常量。

`<id>` 与 `index.html` 里 `NODES[].id` 一一对应。
