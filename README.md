# 火影忍者 · 人物关系图谱

一个**单文件、离线可用**的交互式人物关系图谱。用浏览器打开 `index.html` 即可，不需要联网、不需要安装任何东西、没有任何外部依赖。

37 位角色 · 60 条关系 · 99 条名言 · 每人一句**四字评**。

---

## 三种视图

| 视图 | 看什么 |
| --- | --- |
| **分区 · 按阵营** | 按 木叶 / 宇智波 / 晓 / 砂隐 / 千手 分块，看阵营与阵营之间的恩怨 |
| **分层 · 按世代** | 五栏从左到右＝时代推进：战国 → 三忍一代 → 水门一代 → 第七班 → 新时代 |
| **聚焦 · 点谁看谁** | 点任意头像，只留这一个人的全部关系，并按关系类型分成弧带 |

## 情感镜头（`结构` / `情感` 切换）

顶部那组 `结构 · 情感` 是一个**镜头开关**，叠加在上面三种视图上：

- **结构镜头** —— 看关系的*类型*：血缘 / 师徒 / 队友 / 羁绊 / 宿敌 / 操控
- **情感镜头** —— 看关系的*温度*：**线越粗越亮＝情感浓度越高**，头像外圈的顏色＝这段关系背后的驱动力

七种情感驱动力：**认同 · 守护 · 爱 · 忠诚 · 孤独 · 仇恨 · 野心**

点击侧栏里的某一种，就只看这一种；再点一次，恢复全部。

## 名言 · 名场面

- 详情面板里，每个人物都有「名言 · 名场面」卡片，并写明**这句话是在什么场景下说的**
- 左下角 `名言 · 名场面`（快捷键 `Q`）打开全屏总览：99 条金句 / 37 位角色 / 8 个主题，支持搜索与主题筛选、随机抽一句

## 关于数据

## 部署

改完 `index.html` 后：

```bash
# 1) 推 GitHub
git add -A && git commit -m "update" && git push

# 2) 推 Cloudflare Pages
wrangler pages deploy .deploy --project-name kyuubi --branch main
```

`wrangler` 会把 `.deploy` 目录里的文件整体传上去，所以把要发布的文件放进 `.deploy` 即可（本仓库只需要 `index.html`）。首次在本机使用需要先 `wrangler login`。
