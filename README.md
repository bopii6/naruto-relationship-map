# 火影忍者 · 人物关系图谱

一个**单文件、离线可用**的交互式人物关系图谱。用浏览器打开 `火影忍者-人物关系图谱.html` 即可，不需要联网、不需要安装任何东西、没有任何外部依赖。

37 位角色 · 60 条关系 · 99 条名言。

---

## 三种视图

| 视图 | 看什么 |
| --- | --- |
| **分区 · 按阵营** | 按 木叶 / 宇智波 / 晓 / 砂隐 / 千手 分块，看阵营与阵营之间的恩怨 |
| **分层 · 按世代** | 五栏从左到右＝时代推进：战国 → 三忍一代 → 水门一代 → 第七班 → 新时代 |
| **聚焦 · 点谁看谁** | 点任意头像，只留这一个人的全部关系，并按关系类型分成弧带 |

## 情感镜头（`结构` / `情感` 切换）

顶部那组 `结构 · 情感` 是一个**镜头开关**，叠加在上面三种视图上：

- **结构镜头** —— 看关系的*类型*：血缘 / 师徒 / 队友 / 羁绊 / 宿敌 / 操控
- **情感镜头** —— 看关系的*温度*：**线越粗越亮＝情感浓度越高**，头像外圈的顏色＝这段关系背后的驱动力

七种情感驱动力：**认同 · 守护 · 爱 · 忠诚 · 孤独 · 仇恨 · 野心**

点击侧栏里的某一种，就只看这一种；再点一次，恢复全部。

## 名言 · 名场面

- 详情面板里，每个人物都有「名言 · 名场面」卡片，并写明**这句话是在什么场景下说的**
- 左下角 `名言 · 名场面`（快捷键 `Q`）打开全屏总览：99 条金句 / 37 位角色 / 8 个主题，支持搜索与主题筛选、随机抽一句

## 操作

| 操作 | 效果 |
| --- | --- |
| 点头像 | 进入聚焦视图 |
| 悬停 | 看这一条关系 |
| 滚轮 | 缩放 |
| 拖空白 | 平移 |
| `Esc` | 返回 |
| `/` | 搜索角色 |
| `Q` | 名言总览 |

## 关于数据

- 人物关系、阵营归类、情感浓度**均为个人主观整理**，不是官方设定，欢迎自行调整
- 金句是**日语原句的中文意译**，并标注了单行本卷数与场景
- 天天 / 角都 / 勘九郎 等角色在原著中确实没有标志性台词，因此只收录 1 条，未做编造
